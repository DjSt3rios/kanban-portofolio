# A simple kanban board with Angular and NestJS

### Minimum node version to run the project: v22.22.3 or v24.15.0 or v26.0.0

### How to run the project

1. Clone the repo or download it as a ZIP
2. Install NodeJS from https://nodejs.org/en/download
3. Install pnpm globally by running `npm i pnpm -g`
4. Navigate to the main folder of the project within your terminal
5. Run `pnpm i`
6. Run `pnpm run dev`
7. Navigate to http://localhost:4200
